# Seahawks Nester

Server component of Seahawks Monitoring System. Responsible for centralizing data from Harvester clients and providing a web interface for data visualization.

## Features
- REST API for data collection
- Web interface for monitoring
- Data storage and analysis
- Multi-client support

## Installation
```bash
pip install -r requirements.txt
```

## Usage
```bash
python app.py
```

## Configuration
Edit `config/settings.json` to configure:
- Server port and host
- Database settings
- API authentication
- Logging preferences
